# Ilmli Bolajon

3–7 yoshli bolalar uchun ta'limiy PWA: **MUHABBAT → SHUKR → TAFAKKUR → ILM → AMAL**.
Reklamasiz, xaridsiz, kuzatuvsiz, to'liq offline.

```bash
npm install
npm run dev      # http://localhost:5173/Bilimli-bolajon/
npm test         # unit testlar
npm run e2e      # mobil e2e + screenshots/
npm run build    # dist/
```
